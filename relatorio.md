# Relatório – Atividade Docker com Python

## Introdução
Esta atividade teve como objetivo criar e executar containers Docker utilizando a linguagem Python, demonstrando a criação de imagens, execução de containers e o uso de mapeamento de volumes.

## Atividades Realizadas
1. Foi criado o repositório a partir do fork disponibilizado no GitHub.
2. Foram desenvolvidos dois programas em Python: `alomundo.py` e `calculadora.py`.
3. Foi construído um Dockerfile baseado no Fedora, com instalação do Python.
4. A imagem Docker foi criada e os programas executados dentro de containers.
5. O mapeamento de volume foi testado com sucesso, permitindo edição em tempo real.

## Considerações Finais
A atividade possibilitou compreender o funcionamento de containers, a construção de imagens Docker e o isolamento de ambientes. O uso do volume demonstrou a integração entre host e container, reforçando conceitos de portabilidade e reprodutibilidade de ambientes de desenvolvimento.
